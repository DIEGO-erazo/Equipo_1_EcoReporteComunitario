## 📌 Descripción del Proyecto
EcoReporte Comunitario es una plataforma web orientada a registrar, organizar y dar seguimiento a problemáticas ambientales (acumulación de basura, botaderos clandestinos y fallas en la recolección) en comunidades de El Salvador.
